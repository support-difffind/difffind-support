Contact us

Didn't find what you needed in the guides or FAQ? We're happy to help.

Email us at support@difffind.com We read every message and aim to get back to you as soon as we can.

Before you write in

A few quick checks that often save a round-trip:

  • Check the FAQ — it covers the questions we hear most.
  • If something in the app isn't working the way a guide says it should, try Reset in the toolbar first — it restores all comparison options and content to their defaults.
  • If you're integrating with the API, double-check your request against the API guide or the live docs at app.diffind.com/docs.

What to include

To help us answer quickly, include as much of this as applies:

  • The email address on your account, if you're signed in.
  • What you were trying to do, and what happened instead.
  • The comparison Format and Analysis mode you were using (Plain/URL/curl/File, JSON/YAML/XML/CSV/Text, and whether semantic analysis was on).
  • If you saw an error, the exact error text.
  • For account or billing questions specifically, note that in your subject line.
Never send us a full API key or password. If you need to show us a key for troubleshooting, send only the first/last few characters (the same "hint" shown in Settings) — we'll never ask for the whole thing.
