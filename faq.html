Frequently asked questions

Can't find your answer here? Contact us.

General
Do I need an account to use DiffFind?
No. You can paste content and compare it, including with the default Heuristic AI provider, without signing in. Signing in with Google just saves your AI provider settings to your account so they follow you across devices — see Account & Settings.
Is DiffFind free to use?
There's no billing or subscription in DiffFind today — the deterministic comparison and the Heuristic AI provider are available with no payment required. If you connect a real AI provider (Claude, OpenAI, Gemini), you'll use your own API key with that vendor, subject to their own pricing.
What formats does DiffFind support?
Text, JSON, YAML, XML, and CSV (compared structurally), plus PDF via the File loader. Markdown, HTML, and source-code comparison aren't available yet. See Supported formats.
Comparing documents
Why didn't reordering my JSON keys show up as a change?
JSON, YAML, XML, and CSV are compared structurally — as a parsed value tree, not as text — so key order and formatting never register as a change. Only the actual values changing does. See Supported formats.
Can I compare two PDFs against each other?
Yes — load both sides via the File loader. When both are PDF-sourced, Compare highlights changes directly on the rendered pages instead of the usual line-based view. See Comparing PDFs.
The content I loaded from a URL or curl command is one unreadable line — what now?
Turn on Pretty print in the toolbar. It reformats minified JSON/YAML/XML/CSV into readable, indented text, and your original content is preserved underneath — unchecking it restores it exactly. See Pretty print.
A CSV change doesn't have a clickable line number — is that a bug?
No, that's a known current limitation. Text, JSON, YAML, and XML changes all jump to an exact source line when you click a change card; CSV changes carry a path (e.g. row 3's price column) but don't have that line-lookup yet.
Can I mix sources — say, a URL on one side and pasted text on the other?
Yes. Each Before/After panel has its own independent loader (Plain, URL, curl, or File), so you can mix and match freely.
AI semantic analysis
Do I need an API key to get AI explanations of my changes?
No. The default Heuristic provider generates interpretations without any key or network call. An API key is only needed if you choose a real provider (Claude, OpenAI, or Gemini) for potentially deeper analysis. See Choosing a provider.
Why did my comparison fail with an error instead of just showing a result?
If you're using a real AI provider, a malformed or off-schema response from that vendor fails loudly rather than silently guessing, and a failure to reach the vendor's API (bad key, rate limit, network issue) surfaces as its own error. This is deliberate — DiffFind would rather show you an error than a quietly-wrong interpretation.
What does it mean when a change is shown as "unverified"?
Every AI interpretation is checked against your source documents for factual values it cites (numbers, dates, percentages, etc.). "Unverified" means a cited value wasn't actually found in your source — treat that interpretation with extra scrutiny. See Verification.
Account & data
Is my compared content stored on DiffFind's servers?
No, not beyond what's needed to generate the response. Your comparison history and options are saved only in your own browser. See Privacy & Security.
How is my AI provider API key protected?
If you're signed in, it's encrypted at rest and only ever decrypted to serve your own requests. If you're not signed in, it stays in your browser's local storage and is sent only with your own requests. See API keys.
How do I delete my account or data?
There's no self-service delete button yet — contact us from the email address on your account and we'll take care of it.
